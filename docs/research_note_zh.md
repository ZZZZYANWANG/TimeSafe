# TimeSafe v0.3：把量化研究的“因果时钟”变成可执行合同

量化研究中的未来信息，往往不是显式的 `shift(-1)`，而是全样本标准化、全样本 PCA、双向滤波、事后连续合约、未来回填，或者尚未成熟的标签已经被写进历史面板。TimeSafe 将这些风险拆成四个可以独立验证的问题。

第一，纯函数因子是否满足前缀不变性：

\[
F(D_{1:t}) \stackrel{?}{=} F(D_{1:T})_t.
\]

第二，对模型、PCA、Scaler 等可训练状态，是否在每个历史检查点创建全新模型并只使用合法历史重新拟合。scikit-learn 模型直接调用官方 `clone`，不自行实现不可靠的复制协议。

第三，数据值虽然已经存在于表中，但在当时是否真正可用。TimeSafe 可以按当前模型训练时点遮蔽尚未成熟的标签，也可以按每一行自己的历史决策时点遮蔽尚未发布的特征。

第四，决策、成交、退出、标签成熟、purge、安全间隔和 embargo 是否构成一致的时间合同。区间表不仅保存合同指纹，还会在有交易日历时逐行重新计算端点，防止旧合同或手工修改被错误接受。

证据语义保持克制：全量检查且存在可比较证据才是 `PASS`；抽样无异常为 `WARN`；没有实际扰动或输出为 `INCONCLUSIVE`；发现改写为 `FAIL`。

项目还使用 ACTR-20 脱敏公开模型做真实实验：完整复算 109,499 行匿名基准，并对合法 fresh-state 训练、可得性遮蔽、故意全样本训练、故意未成熟标签、重拟合确定性和20日标签合同分别审计。合法路径保持稳定，两个故意泄漏的负对照均被拒绝。

TimeSafe 不判断策略是否过拟合、机制是否真实或交易成本是否合理。它解决的是更前置的问题：**这个历史结论是否在时间上有资格进入后续统计和交易评价。**
